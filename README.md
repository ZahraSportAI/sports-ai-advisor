## 🚀 پروژه اصلی: مشاور ورزشی هوشمند (Sports AI Advisor)

یک سیستم مشاورهی هوشمند مبتنی بر **RAG (Retrieval-Augmented Generation)** و **Agent Design** که به سوالات تخصصی حوزهی ورزش و فیزیولوژی پاسخ میدهد.

### ✨ ویژگیها:
- **موتور جستجوی هوشمند:** با استفاده از **LangChain** و **ChromaDB**، مرتبطترین پاسخها را از پایگاه داده پیدا میکند.
- **ایجنت با حافظه:** مکالمه را به خاطر میسپارد و سوالات مبهم را درک میکند.
- **رابط کاربری وب:** اپلیکیشنی تعاملی با **Streamlit** که به راحتی قابل اجرا و استفاده است.
- **کاملاً آفلاین:** با استفاده از مدلهای محلی HuggingFace، بدون نیاز به اینترنت کار میکند.

### 🛠️ تکنولوژیها:
- Python
- LangChain
- ChromaDB
- HuggingFace Embeddings (all-MiniLM-L6-v2)
- Streamlit
- Git

### 🎯 کاربردها:
- پاسخ به سوالات تخصصی فیزیولوژی ورزشی
- کمک به مربیان و ورزشکاران برای تصمیمگیری بهتر
- تحلیل دادههای تمرینی (قابل گسترش)
