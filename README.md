🚀 پروژه ۱: مشاور ورزشی هوشمند (Sports AI Advisor)
یک سیستم مشاوره‌ی هوشمند مبتنی بر RAG (Retrieval-Augmented Generation) و Agent Design که به سوالات تخصصی حوزه‌ی ورزش و فیزیولوژی پاسخ می‌دهد.

✨ ویژگی‌ها:
- موتور جستجوی هوشمند: با استفاده از LangChain و ChromaDB، مرتبط‌ترین پاسخ‌ها را از پایگاه داده پیدا می‌کند.
- ایجنت با حافظه: مکالمه را به خاطر می‌سپارد و سوالات مبهم را درک می‌کند.
- رابط کاربری وب: اپلیکیشنی تعاملی با Streamlit که به راحتی قابل اجرا و استفاده است.
- کاملاً آفلاین: با استفاده از مدل‌های محلی HuggingFace، بدون نیاز به اینترنت کار می‌کند.

🛠️ تکنولوژی‌ها:
- Python
- LangChain
- ChromaDB
- HuggingFace Embeddings (all-MiniLM-L6-v2)
- Streamlit
- Git

🎯 کاربردها:
- پاسخ به سوالات تخصصی فیزیولوژی ورزشی
- کمک به مربیان و ورزشکاران برای تصمیم‌گیری بهتر
- تحلیل داده‌های تمرینی (قابل گسترش)

🚀 نحوه‌ی اجرا (پروژه ۱):
۱. مخزن را کلون کنید:
git clone https://github.com/ZahraSportAI/sports-ai-advisor.git
cd sports-ai-advisor
```

۲. کتابخانه‌های مورد نیاز را نصب کنید:
pip install -r requirements.txt
```

۳. اپلیکیشن را اجرا کنید:
streamlit run app.py
```

✅ پس از اجرا، اپلیکیشن در مرورگر شما باز می‌شود و می‌توانید از آن استفاده کنید.


🧠 پروژه ۲: سیستم تحلیل احساسات مشتریان (Customer Sentiment Analysis)

🛠️ تکنولوژی‌ها:
- Python
- Few-Shot Prompting
- Chain-of-Thought (CoT)
- تحلیل داده و گزارش‌سازی
```
